အရေးကြီးသတင်း

ဗြိတိန်

ဩဂုတ်လမှစ၍ ပုံမှန်အိမ်ထောင်စု၏ စွမ်းအင်ကုန်ကျစရိတ်မှာ တစ်နှစ်လျှင် ပေါင်း ၄၄၃ တိုးလာနိုင်ဟု ခန့်မှန်းထားပါသည်။ ယူကေ အင်ဖလေးရှင်နှုန်းလည်း တစ်နှစ်အတွင်း အမြင့်ဆုံးသို့ ရောက်ရှိနေပါသည်။ BBC ›
