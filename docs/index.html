အရေးကြီးသတင်း

မသန်စွမ်းသူအချို့ကို ပိုမြန်မြန်ငွေပေးချေဖို့ အကြံပြုချက် ထွက်လာပါတယ်။ Timms ပြန်လည်သုံးသပ်ချက်အရ ပြင်းထန်သော အခြေအနေရှိသူတွေက Pip အတွက် ထပ်မံစစ်ဆေးရန် မလိုတော့ဘူးလို့ အကြံပြုထားပါတယ်။ BBC ›
